# TICKET-019: Login-/Tägliche Punkte

**Typ:** Requirement

**Status:** umgesetzt

**Beschreibung:**
Der Wald wächst auch etwas heran, wenn man sich einloggt. Es wäre gut, Punkte zu bekommen, wenn man sich einfach nur einloggt – z.B. jeden Tag 2 Punkte, wenn man mal drin ist.
