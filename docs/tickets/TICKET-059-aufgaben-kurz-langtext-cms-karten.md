# TICKET-059: Aufgaben – Kurz-/Langbeschreibung (CMS) und einheitliche Kartenhöhe

**Typ:** Bug / Requirement

**Status:** offen

**PDF-Bug:** 004

**Abgleich:** [TICKET-020-aufgaben-kategorien-kacheln.md](TICKET-020-aufgaben-kategorien-kacheln.md) / [021](TICKET-021-aufgaben-unterseiten-kategorien.md) beschreiben Kategorien-IA, **nicht** separate CMS-Felder Kurz vs. Detail.

**Priorität (laut PDF):** Hoch

**Beschreibung:**
Lange Beschreibungen in Aufgabenkarten zerstören das Grid. Gewünscht: **Kurzbeschreibung** (Teaser, ca. 50–60 Zeichen / 1–2 Zeilen) in der Übersicht; **Detailbeschreibung** nur in der Aufgaben-Detailansicht; Backend-Felder entsprechend; Migration/Fallback für Bestandsaufgaben.

**Quelle:** PDF Bug-tracker, Bug 004.
