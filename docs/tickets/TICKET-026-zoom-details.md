# TICKET-026: Zoom Min/Max für hochauflösendere Details

**Typ:** Idee

**Status:** offen

**Beschreibung:**
Überlegung, ob Zoom Min und Max so definiert werden, dass die Details hochauflösender aussehen, weil man nicht näher rankommt – damit könnte es noch hochwertiger aussehen.
