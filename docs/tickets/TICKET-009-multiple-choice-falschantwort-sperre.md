# TICKET-009: Multiple Choice – Sperre bei Falschantwort

**Typ:** Requirement

**Status:** next

**Beschreibung:**
Bei Falschantwort soll ein definierbarer Zeitraum die erneute Antwort sperren, und die Zeit soll dem User angezeigt werden (z.B. „Die Antwort war leider falsch. Probiere es in X Minuten noch einmal“). Aktuell kann man einfach klicken, bis man das Richtige trifft.

**Quelle:** Kundenmail
